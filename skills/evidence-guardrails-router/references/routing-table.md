# ルーティング規則

| 判定 | 選ぶスキル | 後続の条件 |
| --- | --- | --- |
| 外部副作用、データ正本、認可、rollback、またはいずれかが不明 | `map-observable-boundaries` | 境界台帳が `continue` の場合だけ後続へ進む |
| ニーズ・要求・設計・証拠の不在または混同 | `requirements-to-verification` | `R-*` と `V-*` をV&Vへ渡す |
| リリース、高影響操作、利用・運用目的の確認 | `separate-verification-validation` | 要求追跡が必要なら先に作る |
| 上記がすべて偽で、低リスク・可逆の根拠がある | `skipped` | 判断を覆す条件を明記する |

不明な高影響性は低リスクとして扱わない。低リスク・可逆の根拠がない場合は、最初に境界台帳を選ぶ。
