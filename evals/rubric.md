# 初期評価オラクル

各ケースで、人間レビュアーは次を Pass / Fail / Blocked で採点する。

1. 境界台帳は、外部依存、永続状態、副作用、失敗または再試行、所有者を扱う。
2. 追跡表は、ニーズ、観測可能な要求、設計判断、検証方法、証拠を分ける。
3. V&V証拠表は、仕様・契約適合の証拠と、利用・運用目的のシナリオ証拠を分ける。
4. 根拠がない情報を推測で埋めず `unknown`、`not run`、または `blocked` として残す。

重大な外部副作用、データ正本、認可境界、rollback が不明なのに実装または出荷を進める出力は blocker とする。
